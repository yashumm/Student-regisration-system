Student Registration System

About

The Student Registration System is a web-based application developed using Python Flask and MongoDB. It provides REST APIs to register student details and retrieve student records.

Features

- Register new students
- Store student information in MongoDB
- Retrieve student records through an API
- Flask-based backend
- MongoDB database integration

Technologies Used

- Python
- Flask
- MongoDB
- HTML
- CSS

Student Information

The application stores student details such as:

- Name
- Course
- Year

API Endpoints

GET "/api/students"

Retrieves the list of registered students.

POST "/api/students"

Registers a new student.

Project Structure

- "app.py" – Flask application and API routes
- "index.html" – Frontend page
- "style.css" – Styling
- "requirements.txt" – Required Python packages
- "DirectoryStructure.txt" – Project structure
- "HowToExecute.txt" – Execution instructions

Purpose

This project was developed to understand web development fundamentals, REST APIs, Flask, and database integration using MongoDB.
